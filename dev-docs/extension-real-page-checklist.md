# 扩展直连通道：真实页面走查清单

本清单对应[扩展产品方向](extension-direction.md)「验证状态」里的**未验证**项：真实的 1688 / Ozon 页面、真实生图服务、
真实 Ozon 上架、真实 ERP 托管与同步、打包版在浏览器里的流程。自动化验证用的都是本地夹具，这些只能由人在真实环境里走一遍。

规则与边界以方向文档为准，这里只写怎么查。界面文字取自 2026-11-12 的代码；标注“记录看到的文字”的地方表示没有逐字核对，
以实际界面为准并把原文记下来。

## 怎么用

- 按 A → E 的顺序做。**A、B 不花钱也不写入**；**C 会产生生图费用**；**D 会在真实 Ozon 店铺创建商品**。
  C、D 不想做可以跳过，在记录表里写“未做”。
- 每一项记录：通过 / 不通过 / 未做，不通过的附截图和你看到的提示文字。
- 出错时同时截取后台日志：`chrome://extensions` → 本扩展 →「Service Worker」。

## 0. 准备

1. 构建：按平时的方式执行 `pnpm build:extension:cloud` 或 `pnpm build:extension:local`，
   产物在 `build/extensions/ss-erp-cloud` 或 `build/extensions/ss-erp-local`。
2. 加载：`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选上一步的产物目录（不要选源码目录
   `extensions/ss-erp`，要验证的是打包版）。
3. **如果这个浏览器里已经装了正式发布的扩展，先停用它**，或者换一个干净的 Chrome 用户配置。两份同时启用会各自往页面里注入一次，
   出现两个入口，结论就不可信了。
4. 准备好：一个 1688 商品链接；一个可以承受一条测试商品的 Ozon 店铺的 Client-Id 与 Api-Key；
   一个兼容 OpenAI 图片接口的生图服务（地址、模型、密钥），并知道它每张图大约多少钱。

## A. 入口与界面（不花钱、不写入）

| 编号 | 做什么 | 应该看到 |
|---|---|---|
| A1 | 打开 1688 商品页 | 页面上只有一个悬浮入口「SS ERP」，没有其它旧的悬浮按钮。点开有四个标签：「上架工作台」「采集 / 跟卖」「利润计算」「商品信息」；前者与「利润计算」可点，另外两个置灰，悬停提示以「当前页面不适用：」开头 |
| A2 | 观察入口外观与页面 | 入口和菜单是磨砂半透明加淡紫色；页面自身的内容没有被遮挡、错位或变色；滚动、缩放窗口后入口位置正常 |
| A3 | 在 1688 点「利润计算」再关闭 | 核价面板打开；面板展开期间入口收起，关闭后入口回来 |
| A4 | 点「上架工作台」 | 全屏工作台打开，步骤条依次是「采集」「类目」「AI 分析」「图片」「上架」；商品标题、SKU、来源图显示正确 |
| A5 | 关闭工作台 | 回到 1688 页面，入口回来，页面可正常滚动 |
| A6 | 打开 Ozon 商品页，等页面加载完再等 5 秒 | 只有一个入口并且**一直可见**。标签里「采集 / 跟卖」「利润计算」「商品信息」可点，「上架工作台」置灰；菜单下方有「同步 Ozon Cookie」 |
| A7 | 点「商品信息」 | 「Ozon 数据一览」面板展开，副标题里的 SKU 与当前页面的商品一致；点收起后**不留**左侧的折叠条，入口回来 |
| A8 | 展开「商品信息」后，点页面里的另一个商品（站内跳转，页面不整页刷新） | 面板保持展开，SKU 变成新商品的；入口菜单里没有残留上一个商品的状态文字 |
| A9 | 从 Ozon 商品页点进类目页或搜索页 | 「采集 / 跟卖」「商品信息」变为置灰，「利润计算」仍可点 |
| A10 | Ozon 商品页点「利润计算」；再站内切到另一个商品重复一次 | 两次算出的都是当前商品的数据 |
| A11 | 打开 Ozon 搜索 / 列表页、Ozon 卖家后台 | 记录看到的文字和按钮（列表选品规则已冻结，不应出现新的入口） |
| A12 | 打开一个淘宝或拼多多商品页 | 不出现「上架工作台」与核价面板的入口 |
| A13 | 点浏览器工具栏里的扩展图标 | 弹窗正常打开（标题「松鼠跨境助手」），没有报错；记录「ERP 后端」一栏显示的状态文字 |

## B. 密钥、权限与类目（不花钱）

| 编号 | 做什么 | 应该看到 |
|---|---|---|
| B1 | 工作台里点「设置」，找到「直连密钥」 | 三组：「Ozon 店铺」「生图服务」「AI 文本（视觉描述 / 标题）」；有提示「密钥只保存在这台电脑的浏览器里，不会上传到 ERP。多人共用电脑时请勿保存。」 |
| B2 | 填 Client-Id 与 Api-Key，点「保存 Ozon 密钥」 | 先显示「正在保存并检查连接…」，随后「已保存并连接成功：Client-Id …」 |
| B3 | 关闭设置再打开 | 显示「已配置：Client-Id …」；Api-Key 输入框是空的，密钥**没有**回显 |
| B4 | 故意填一个错误的 Api-Key 保存 | 「已保存，但连接检查未通过：…」，记录后面的原因文字；然后改回正确的 |
| B5 | 「生图服务」的服务地址填 `http://` 开头的地址保存 | 被拒绝，提示「服务地址必须以 https:// 开头」 |
| B6 | 填正确的服务地址、模型、密钥，点「保存生图服务」 | 浏览器弹出访问该地址的权限请求；允许后保存成功。记录权限弹窗里列出的网址 |
| B7 | （可选）换一个地址再保存，这次在权限弹窗里点拒绝 | 提示以「浏览器没有授予访问」开头，没有保存成可用状态 |
| B7a | 「AI 文本（视觉描述 / 标题）」填服务地址、模型、密钥（地址和模型留空用默认值），点「保存 AI 文本服务」 | 浏览器询问访问该服务地址的权限；允许后显示「已保存：模型名」，密钥输入框被清空。重新打开设置显示「已配置：模型名」 |
| B8 | 点步骤条的「类目」，选一个 Ozon 官方类目并确认 | 「类目」一步显示为完成 |
| B9 | 关闭工作台，刷新 1688 页面，重新打开同一个商品的工作台 | 类目还在（类目保存在本机） |
| B10 | 断开 ERP（退出登录或断网到 ERP）后重复 A4 | 工作台照常打开和使用；记录界面上关于 ERP 未连接的提示文字 |

## C. 生图（会产生费用：先只生成 1 张）

三种方式是「仅翻译」「AI主图＋翻译」「AI套图」。

| 编号 | 做什么 | 应该看到 |
|---|---|---|
| C1 | 点步骤条「图片」，选「仅翻译」，只勾 1 张来源图，开始 | 结果出现在「处理结果」里，状态从「生成中…」到「已完成」；图片能正常显示；图里的中文被换成俄文（记录翻译质量） |
| C2 | 看这张结果图下方 | 有「用于上架」勾选框且默认勾选。ERP 已连接时不应出现未托管的提示。ERP 未连接时：服务商返回的是 https 链接，则出现「未托管到 ERP，链接可能过期」，仍可勾选；服务商只返回图片数据没有链接，则是「仅可预览」「无法上架」。记录看到的是哪一种 |
| C3 | 选「AI主图＋翻译」，针对 1 个 SKU 生成 | 生成 1 张主图；记录用时与观感 |
| C4 | 选「AI套图」生成（张数即费用，先确认数量） | 逐张出现结果；中途点停止后，已完成的图片保留 |
| C5 | 有失败的图片时点「重试失败项」 | 只重新生成失败的那几张；到服务商后台核对计费次数没有把已完成的重算一遍 |
| C6 | 关闭工作台、刷新页面，重新打开 | 之前的结果还在；步骤条「图片」显示为完成（可能有不到一秒的延迟） |

## D. 上架（会在真实 Ozon 店铺创建商品：用一条可以删除的测试商品）

| 编号 | 做什么 | 应该看到 |
|---|---|---|
| D1 | 点步骤条「上架」 | 没选类目时提示「请先选择 Ozon 类目」；选了之后出现属性、价格、库存。有说明「属性由 Ozon 官方字段 + 本地规则预填（未使用 ERP 草稿）」 |
| D2 | 没有配置 AI 文本服务时，点「生成标题」 | 上架面板的「AI 文本：」一行提示未配置；标题按规则生成，「俄文标题」里出现内容 |
| D3 | 做完 B7a 后，点「视觉描述」「生成标题」 | 上架面板的「AI 文本：」一行显示「已配置：模型名」，面板里没有密钥输入框；生成出视觉描述和标题（这一步会产生少量文本模型费用）。记录视觉描述实际使用的模型名 |
| D4 | 填倍率点「按倍率填价」 | 每个 SKU 的售价被填上，提示「已按倍率填价：上架前请核对每一行」 |
| D5 | 点「刷新仓库」 | 列出店铺的仓库；店铺没有 FBS 仓库时提示「（该店铺没有仓库）」 |
| D6 | 点「预检载荷」 | 「预检通过：N 条可上架」；缺内容时是「预检未通过：N 个待补项」。不补齐直接上架会被拦下，提示「预检未通过，先补齐：…」 |
| D7 | 点「上架到 Ozon」 | 显示「上架完成：…」和库存提交结果。到 Ozon 卖家后台确认：商品出现，图片是 C 里勾选「用于上架」的那些，价格和库存正确 |
| D8 | ERP 已连接时，到 ERP 里找对应的采集商品 | 能看到这次上架的结果（货号、Ozon 商品号、最终图片、标题、类目） |
| D9 | ERP 未连接时重复一次上架（或只看提示） | 上架本身成功；有“未同步、可重试”的提示，记录原文 |
| D10 | 对已经上架过的同一个商品，再次打开上架面板 | 价格一栏用 Ozon 线上的现有价预填（标注「线上现有（来自 Ozon）」），不是重新按倍率计算；有说明「属性/尺寸/图片取自 Ozon 已上架商品，未读取 ERP 草稿」。不要在这里大幅改价：Ozon 会把改价幅度过大的商品卡放进价格隔离 |
