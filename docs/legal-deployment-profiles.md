# 法律文档部署配置

环境变量 LEGAL_PROFILE 同时决定用户协议、隐私政策的适用部署说明和同意记录版本。API 与 Web 必须读取同一个环境文件，不能只修改页面显示。

| 使用场景 | 域名或设备 | LEGAL_PROFILE | 数据处理说明 |
| --- | --- | --- | --- |
| 中国大陆云端 | ss-erp.cn 及其子域名 | cloud-cn | 账号与主要业务数据存放在中国大陆云基础设施；连接 Ozon 等境外平台时按用户指令传输必要数据 |
| 国际云端 | ss-erp.com 及其子域名 | cloud-global | 数据可能按实际部署区域存放在境内外云基础设施 |
| 本地设备 | Windows 本地 ERP、localhost | local | 数据主要保存在用户管理的本地设备、数据库或局域网 |
| 独立部署 | 客户自有服务器或专属实例 | self-hosted | 部署方负责说明其服务器位置、第三方服务及额外的数据处理规则 |

## 品牌与签约主体

- 产品品牌：松鼠跨境 ERP
- 页面短名称：厦门常青藤上云
- 完整签约和运营主体：常青藤上云（厦门）网络科技有限公司

导航、登录页和一般品牌区域可以显示短名称。用户协议中的签约方、责任、争议解决，以及隐私政策中的个人信息处理者必须显示完整公司名。

## 部署要求

在每个环境文件中显式设置其中一个值。例如中国大陆云端：

    LEGAL_PROFILE=cloud-cn

国内阿里云使用 cloud-cn，海外 VPS 使用 cloud-global，Windows 本地包使用 local。部署前运行：

    pnpm env:check -- --profile cloud-bootstrap --env .env.staging

注册和首次管理员初始化会把 profile、用户协议版本、隐私政策版本、来源、时间、IP 和 User-Agent 写入 legal_acceptances。修改协议正文时，必须同步提高 packages/shared/src/legal.ts 中对应 profile 的版本号，不能覆盖旧版本号后继续记录。

self-hosted 版本是基础模板。若客户部署方成为独立的个人信息处理者或增加新的第三方服务，应由其补充自己的运营主体、联系方式、服务器位置和处理规则，并在启用注册前完成法律审查。
